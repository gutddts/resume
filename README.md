# 小白 (gutddts) · 个人简历站

网安 × AI 双修 · 渗透测试 · 红队 · 安全工具开发

基于 [happysnaker/Resume](https://github.com/happysnaker/Resume)（MIT License）模板定制。

## 本地运行

```bash
python3 -m http.server 8080
# 打开 http://localhost:8080
```

## 定制

所有内容在 `config/config.js` 中修改：基本信息、座右铭、技能、项目、时间线、社交链接与图片资源。
